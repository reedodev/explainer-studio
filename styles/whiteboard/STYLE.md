# whiteboard · 화이트보드

> 흰 보드 위에 약간 흔들리는 검은 마커 선이 내레이션에 맞춰 한 획씩 그려지는 Excalidraw 풍 설명 영상.

구현: `src/render/styles/whiteboard.ts` · 기본 스타일

## 1. 어울리는 이야기
- 개념 정의 → 구조 → 비교 → 예시 → 주의점처럼 **논리 순서가 분명한 설명**
- 관계를 화살표로 보여주는 내용(원인 → 결과, 입력 → 처리 → 출력)
- 강의·온보딩·제품 원리

## 2. 화면 언어
| 항목 | 값 |
|---|---|
| 바탕 | `#ffffff` 단색 |
| 선 | `#1b1b1b`, 두께 3px, Rough.js(roughness 1.1)로 약간 흔들림 |
| 채움 | 파스텔 5색(`yellow #ffec99`, `blue #a5d8ff`, `green #b2f2bb`, `red #ffc9c9`, `grey #e9ecef`) 55% |
| 글꼴 | Gaegu(OFL) 손글씨 |
| 강조 | marker = 형광펜(multiply), underline = 손 밑줄, circle = 손 동그라미 |

## 3. 움직임
- text: 펜이 지나가듯 왼쪽에서 오른쪽으로 써짐
- rectangle: 네 변을 차례로 → 채움 → 라벨
- arrow: 선 먼저, 화살촉 나중
- circle: 한 바퀴 돌며 그림
- sticker/image: 빠르게 커지며 등장

## 4. 전환
지우개 와이프: 이전 장면이 왼쪽부터 회색 지우개 자국과 함께 지워집니다(0.55초).

## 5. 자막
하단 흰 띠, 맑은 고딕 38px, 검정.

## 6. 소리 가이드(수동)
마커 끽 소리, 뚜껑 딸깍, 지우개 문지르는 소리. 음악은 가볍고 건조한 어쿠스틱. 현재 엔진은 내레이션만 믹스합니다.

## 7. 스토리보드 팁
- 한 장면 요소 6–10개, 제목 64–70px, 본문 44–56px
- 박스 안 글씨는 `label`로 넣으면 자동 가운데 정렬
- 아이콘은 박스 위나 옆에 두고 겹치지 않게

## 8. 피하기
- 한 화면을 꽉 채우는 표
- 파스텔 위 파스텔 겹치기
