# urban-sketch · 펜 담채 스케치

> 벤치에 앉아 그린 스케치북 한 페이지. 세피아 펜선은 흔들리고 삐져나가며, 투명 수채는 선을 살짝 벗어나 번집니다.

구현: `src/render/styles/urban-sketch.ts`

## 1. 어울리는 이야기
- 경험담·후기·일상 속 발견
- 공간·여행·루틴처럼 장면이 떠오르는 설명
- 부드럽고 따뜻한 톤의 가이드

## 2. 화면 언어
| 항목 | 값 |
|---|---|
| 종이 | 크림 `#F5EEDE` + 얼룩 + 가장자리 비네트 |
| 펜 | `#2B2520` 2.2–2.6px, 흔들림, 양 끝 3–9px 넘침, 긴 선은 한 번 끊김 |
| 수채 | `yellow #E8C35E`, `blue #86B3D6`, `green #A9BF5A`, `red #E1907E`, `grey #BDB5A6`. multiply, 세 겹, 선에서 약간 어긋남, 마른 가장자리 |
| 글꼴 | 나눔펜(OFL) 손글씨 |
| 강조 | marker = 수채 띠, underline = 두 줄 펜 밑줄, circle = 겹쳐 닫히는 원 |

## 3. 움직임
- 도형: 펜 윤곽 먼저(0–60%) → 수채가 가운데서 퍼짐(45–100%)
- 글자: 펜으로 써 내려감
- 스티커: 종이에 스며드는 느낌으로 등장

## 4. 전환
수채 번짐: 왼쪽 아래에서 젖은 물감이 퍼지며 새 페이지가 드러나고, 번짐 가장자리에 파란 물 자국이 남습니다(0.7초).

## 5. 자막
크림색 띠 위 나눔펜 50px.

## 6. 소리 가이드(수동)
펜촉 사각거림, 붓 물 헹구는 소리, 공원 앰비언스. 어쿠스틱 기타·우쿨렐레.

## 7. 스토리보드 팁
- 손글씨 폰트는 글자 폭이 좁아 보이므로 엔진이 1.3배 키움 → 텍스트 박스를 여유 있게
- 색은 장면당 2–3가지

## 8. 피하기
- 꽉 찬 채색(종이 여백이 사라짐)
- 딱딱한 직선 도표 위주 장면(blueprint가 더 적합)
