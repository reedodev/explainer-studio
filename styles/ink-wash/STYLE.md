# ink-wash · 수묵화

> 따뜻한 화선지 위, 붓 한 획이 산이 되고 물결이 됩니다. 여백이 공간이고, 붉은 낙관 하나만이 색입니다.

구현: `src/render/styles/ink-wash.ts`

## 1. 어울리는 이야기
- 태도·철학·관점처럼 **생각을 곱씹게 하는** 메시지
- "비워야 보인다", "하나만 남긴다" 같은 역설
- 동양 문화, 시, 느린 호흡의 성찰

## 2. 화면 언어
| 항목 | 값 |
|---|---|
| 바탕 | 화선지 `#F2ECDE` + 구름 얼룩 + 섬유 + 미세 반점 + 옅은 비네트 |
| 먹 | `#1A1714`. 붓선은 시작·끝이 가늘고 가운데가 굵은 압력 곡선 + 비백(마른 붓 줄무늬) |
| 담채 | 토큰별 옅은 먹빛(`yellow` 황토, `blue` 화청, `green` 녹묵, `red` 주홍, `grey` 담묵) 10–20%, 번진 가장자리 두 겹 |
| 윤곽 | 사각형은 두 획으로, 모서리 앞에서 붓을 뗌 |
| 글꼴 | 나눔명조(OFL) ExtraBold/Bold |
| 강조 | marker = 붉은 낙관(核心) 도장, underline = 굵은 붓 밑줄, circle = 열린 원 |

## 3. 움직임
- 붓선: 경로를 따라 굵기가 변하며 그려짐
- 담채: 작게 떨어져 퍼지며 번짐
- 글자: 한 글자씩 먹이 스미듯 진해짐(번짐 → 선명)
- 스티커: 회색조로 종이에 스며듦(multiply)

## 4. 전환
먹물 번짐: 화면 중앙에 떨어진 먹이 이전 장면을 덮고, 다시 옅어지며 새 장면이 드러납니다(0.8초).

## 5. 자막
종이색 띠 위 명조 Bold 38px.

## 6. 소리 가이드(수동)
붓이 종이를 스치는 소리, 물방울, 대금·가야금 한두 음. 절정 전 완전한 침묵.

## 7. 스토리보드 팁
- 요소 수를 줄이세요(장면당 4–7개). 여백이 곧 스타일
- 강조는 장면당 한 번. `highlight style: marker`가 낙관이 됩니다
- 아이콘도 붓선으로 그려지므로 60px 이상 크게

## 8. 피하기
- 촘촘한 표, 많은 색
- 작은 글씨(명조 획이 가늘어 36px 이상 권장)
