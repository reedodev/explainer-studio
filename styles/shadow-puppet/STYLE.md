# shadow-puppet · 그림자극

> 등잔불이 비치는 무명 스크린. 물들인 가죽 조각에 빛이 스며들고, 새김 윤곽선과 리벳이 보이며, 손에 든 인형처럼 조금씩 떨립니다.

구현: `src/render/styles/shadow-puppet.ts`

## 1. 어울리는 이야기
- 주인공·목표·전환이 있는 **우화·옛이야기형 설명**
- 유래, 역사, "옛날 옛적에" 같은 도입
- 명절·전통·따뜻한 브랜드 스토리

## 2. 화면 언어
| 항목 | 값 |
|---|---|
| 스크린 | 중심이 밝은 등잔 빛 방사 그라데이션(`#FBE3A6` → `#6A3514`) + 무명 결 + 따뜻한 비네트 + 미세한 불꽃 깜빡임 |
| 가죽 염료 | `yellow` 황토 `#DC9D1E`, `red` 주홍 `#B8211A`, `blue` 쪽빛 `#22647E`, `green` 옥빛 `#2F8A5C`, `grey` 생가죽 `#E2BD80` (78% 반투명) |
| 새김 | 윤곽 `#1A100A` 4px, 안쪽 레이스 구멍 줄, 모서리 리벳, 아래로 흐려지는 조종 막대 |
| 글꼴 | 나눔명조 ExtraBold. 어두운 염료 위에서는 밝은 크림 `#F6E3B4` |
| 강조 | marker = 염료 가죽 띠, underline = 주홍 선, circle = 새김 원 |

## 3. 움직임
- 모든 요소가 손떨림처럼 ±1–2px 흔들림(노이즈, 장면 내내)
- 도형: 아래에서 스크린으로 들어 올려짐(60px) + 서서히 선명
- 글자: 페이드 인
- 스티커: 염료 빛깔로 물든 채 들어 올려짐

## 4. 전환
등잔 소등: 이전 장면이 어두워졌다가, 새 장면에서 다시 불이 켜집니다(0.8초).

## 5. 자막
어두운 갈색 띠 위 크림색 명조 38px.

## 6. 소리 가이드(수동)
북·징·해금, 가죽 인형이 스크린에 닿는 "탁", 등잔 타는 소리. 절정 전 정적.

## 7. 스토리보드 팁
- 박스는 "인형"처럼 보이므로 크고 단순하게(최소 250×120)
- 라벨은 짧게. 어두운 염료(`red`, `blue`, `green`)에는 밝은 글씨가 자동 적용
- 스크린 가장자리는 어두우므로 중요한 텍스트는 가운데 60% 안에

## 8. 피하기
- 화면 가장자리의 작은 글씨(비네트에 묻힘)
- 너무 많은 요소(떨림이 산만해짐)
