# blueprint · 블루프린트 설계도

> 청사진(시아노타입) 종이 위 흰 제도선. 흐린 보조선이 먼저 지나가고 본선이 따라오며, 주석은 타자기처럼 찍힙니다.

구현: `src/render/styles/blueprint.ts`

## 1. 어울리는 이야기
- 시스템·아키텍처·파이프라인 구조
- "이 제품은 어떻게 작동하나" 같은 해부형 설명
- 단계별 조립, 부품과 연결

## 2. 화면 언어
| 항목 | 값 |
|---|---|
| 바탕 | 프러시안 블루 `#173F6D` + 얼룩 질감 + 24px 보조 격자 / 120px 주 격자 + 도면 테두리 + 비네트 |
| 선 | `#E7F0F9`, 약한 번짐(glow), 거의 곧은 선(roughness 0.35) |
| 채움 | 45° 해칭. 토큰마다 각도·간격이 다름(`yellow` 촘촘, `blue` -45°, `grey` 수평) |
| 신호색 | 스탬프 레드 `#E0624F` (토큰 `red`) — 가급적 한 번 |
| 글꼴 | 나눔고딕코딩(OFL) 모노스페이스 |
| 강조 | underline = 치수선 `|←→|`, marker/circle = 빨간 수정 표시 원 |

## 3. 움직임
- 선: 점선 보조선이 먼저 1.6배 빠르게 → 본선이 뒤따름
- 도형: 윤곽 → 해칭 → 모서리 치수 틱
- 글자: 한 글자씩 타이핑 + 블록 커서
- 스티커: 흰 선화로 변환되어 점선 테두리 안에 표시

## 4. 전환
스캔 라인: 밝은 가로선이 위에서 아래로 훑고, 선 아래에는 이전 도면이 남습니다(0.6초).

## 5. 자막
짙은 남색 띠 위 모노스페이스 36px.

## 6. 소리 가이드(수동)
연필·펜 긁는 소리, 자 대는 소리, 타자기 키, 도장 "쿵". 음악은 미니멀 앰비언트.

## 7. 스토리보드 팁
- 박스와 화살표 중심의 다이어그램이 가장 잘 어울림
- 라벨은 짧게(모노스페이스라 한글 폭이 넓음)
- 모서리 치수 틱이 생기므로 박스끼리 40px 이상 띄우기

## 8. 피하기
- 파란색·흰색 이외 색 추가
- 긴 문단(타이핑이 오래 걸림)
