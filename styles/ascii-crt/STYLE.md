# ascii-crt · ASCII 터미널

> 호박색 인광의 흑백 CRT. 선과 도형은 문자 격자 한 칸씩 찍히고, 채움은 점묘 음영, 글자는 커서와 함께 타이핑됩니다.

구현: `src/render/styles/ascii-crt.ts`

## 1. 어울리는 이야기
- AI 에이전트·자동화·코드·로그 이야기
- "실행 → 결과 → 다음 명령" 같은 절차
- 레트로·해커 감성의 짧은 팁

## 2. 화면 언어
| 항목 | 값 |
|---|---|
| 유리 | 꺼진 유리 `#0B0805` |
| 인광 | 호박색 `#FFB33A`, 보조색 연녹 `#9CFFB5`(토큰 `red`) |
| 격자 | 셀 14×26px. 모든 선·원·아이콘은 셀 단위 글리프(─ │ ╱ ╲)로 래스터화, 모서리 ┌┐└┘ / 원은 ╭╮╰╯ |
| 채움 | 셀 점묘 음영(░ ▒) 22–30% |
| 글꼴 | 나눔고딕코딩(OFL). 박스 선·음영·화살촉은 폰트 대신 벡터로 그려 칸 사이가 끊기지 않음 |
| 후처리 | 인광 번짐(1/6 축소 후 확대 가산), 3px 주사선, 유리 비네트 |
| 강조 | marker = 반전 블록, underline = ▀ 줄, circle = 보조색 원 |

## 3. 움직임
- 선·도형: 칸이 순서대로 켜짐(윤곽 → 음영)
- 화살표: 선 → 끝 칸에 ►
- 글자: 한 글자씩 + 블록 커서
- 스티커: 셀 밝기에 따라 ` .:-=+*#%@` 문자 그림으로 변환, 위에서부터 줄 단위 출력

## 4. 전환
clear: 이전 화면이 위에서부터 한 줄씩 지워지고 커서가 내려갑니다(0.5초).

## 5. 자막
검은 띠 위 `> ` 프롬프트 + 호박색 모노 36px, 왼쪽 정렬.

## 6. 소리 가이드(수동)
기계식 키보드, 모뎀·비프음, CRT 고주파 험, 신스 베이스.

## 7. 스토리보드 팁
- 좌표가 셀 격자로 반올림되므로 박스는 14/26의 배수 근처 크기로
- 한글은 모노 폰트에서 폭이 넓으니 라벨을 짧게
- 강조 대상 텍스트는 한 줄로

## 8. 피하기
- 곡선이 많은 복잡한 아이콘(격자에서 뭉개짐)
- 밝은 배경 스티커를 크게(문자 그림이 과밀해짐)
