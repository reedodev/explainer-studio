# swiss-motion · 스위스 모션 타이포

> 12단 그리드 위 흰 종이, 검정 글자와 블록, 밝은 회색, 그리고 **빨강 하나**. 모든 요소는 그리드에 스냅되며 튕기지 않습니다.

구현: `src/render/styles/swiss-motion.ts`

## 1. 어울리는 이야기
- **체계 + 하나의 예외**로 바꿀 수 있는 주제: "원칙 5가지", "규칙은 이렇고, 이것 하나만 다르다"
- 스레드 글처럼 짧은 문장이 연속되는 메시지
- 브랜드 선언, 발표 요약

## 2. 화면 언어
| 항목 | 값 |
|---|---|
| 바탕 | 흰 종이 `#FFFFFF` + 옅은 12단 그리드 `#ECEBE7` (여백 96px, 거터 24px) |
| 잉크 | `#111111` |
| 신호색 | `#E30613` 단 하나 (토큰 `red`) |
| 채움 매핑 | `yellow` → 검정 블록(글자 흰색), `red` → 빨강 블록, `blue/green/grey` → 밝은 회색 블록 + 윗면 검정 룰 |
| 글꼴 | IBM Plex Sans KR(OFL) Bold/Medium, 왼쪽 정렬 권장 |
| 질감 | 없음. 그림자, 그라데이션, 입자 금지 |

## 3. 움직임
- 곡선은 두 가지뿐: 스냅 `cubic-bezier(.7,0,.2,1)`, 선형
- 블록: 위에서 아래로 와이프
- 글자: 줄마다 기준선 아래 클립에서 올라옴(스냅, 순차)
- 선: 길이 방향으로 선형 성장
- 화살표: 굵은 막대 + 삼각 촉, 스냅
- 강조: 단어 밑 빨간 막대

## 4. 전환
나이프 컷: 빨간 세로선이 왼쪽에서 오른쪽으로 지나가며 이전 페이지를 잘라냅니다(0.5초).

## 5. 자막·타이틀
자막은 레이아웃의 일부처럼 왼쪽 정렬(x=96), 짧은 검정 룰 아래. 커버는 빨간 룰 위 큰 왼쪽 정렬 제목.

## 6. 소리 가이드(수동)
120 BPM 모토릭 비트, 스냅마다 활판 "착" 소리, 선은 펜 "츠-". 예외 요소만 멜로디를 가집니다.

## 7. 스토리보드 팁
- `x`를 96, 314, 532 … (한 칸 218px)에 맞추면 그리드와 정렬됩니다
- 강조하고 싶은 것 하나만 `red`, 나머지는 `yellow`(검정 블록)와 회색으로
- 한 장면 한 문장. 긴 설명은 쪼개기

## 8. 피하기
- 빨강 남용(빨강이 두 개 이상이면 주인공이 사라짐)
- 가운데 정렬 남발, 둥근 모서리, 페이드
